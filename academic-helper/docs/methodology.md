# Методика и границы вывода

Контекст — вымышленный российский вуз, оценки 2–5. 360 студентов из 12 условных групп имеют по три дисциплины: управление данными (ud), базы данных (bd), программирование (pr). Все записи синтетические; персональных данных реальных студентов нет.

Генератор с зерном 42 моделирует скрытые способности, усердие, различия дисциплин и независимый шум. Контрольные и итоговые оценки дискретизируются в 2–5. Будущий результат содержит дополнительную случайную составляющую. Итог не вычисляется напрямую из контрольных; общие скрытые переменные создают корреляцию. Эти зависимости заданы автором, а не установлены исследованием России.

Два CSV имеют разные схемы, но общее происхождение. Журнал охватывает 16 недель: 32 занятия и 8 лабораторных по каждой предметной записи. На дату 29.03.2026 доступны 16 занятий и 4 работы. 21 600 событий после среза исключены. Дубли удаляются до агрегации, конфликтующие ключи вызывают ошибку. Пустые неприменимые поля событий не являются ошибками. Три пропуска control_2 остаются до модельной предобработки.

Таблицы sources, students, enrollments, activities, documents, experiments, requests связаны внешними ключами; схема в er_diagram.mmd. Идентификатор студента S0001 устойчив; запись ud-0001 относится к дисциплине. Коды групп — вымышленные и не являются номером группы автора.

Признаки: control_1, control_2, attendance_rate, lab_completion, late_share, course. Посещаемость = посещено / проведено; сдача = сдано / назначено; просрочки = сдано с опозданием / назначено. Итоговая оценка и события после среза исключены. Скрытые параметры генератора не передаются модели.

Разбиение по student_id: обучение 216 студентов / 648 записей, валидация 72 / 216, тест 72 / 216. Все предметы студента вместе. В обучении StratifiedGroupKFold из 5 частей. MedianImputer, StandardScaler и OneHotEncoder входят в Pipeline и обучаются внутри fold. Выбор модели по средней CV Average Precision; C логистической регрессии 0,1/1/10, RF 200 деревьев с глубиной 4/8/без ограничения и листом 2/5. Порог 0,45 выбран на валидации по F1 (сетка 0,10–0,90 с шагом 0,025). Тест использован после выбора. 500 bootstrap-выборок студентов дают условный 95% интервал F1.

В knowledge 10 документов. Внешний справочник РУДН описывает традиционные оценки, но не подтверждает синтетические записи и правила учебного института. TF-IDF char_wb 3–5 и cosine similarity — лексический поиск, а не нейросетевые embeddings. У инструментов фиксированный список: course_stats, predict_record, list_risk, search_knowledge; произвольный SQL не принимается.

Локальная Qwen3 1,7B 4-bit запускается через MLX. Маршрутизация детерминирована; LLM объясняет результаты. Числовая проверка ограничена буквальным наличием величин и единиц процента, смысл не проверяет. В ручной оценке только сырой generated_answer, добавленная справка оценивается отдельно. 16 запросов не являются независимым тестом общего качества. 10 ответов полные, 1 неполный, 5 ошибочных: перепутана дисциплина; ошибочно исключены контрольные; спутано происхождение; неправильно описан split; неверное начальное «да» для отчисления. Реальный внешний API не запускался.

Демонстрационный список риска использует всю базу, включая обучение, поэтому не измеряет качество. Тестовое качество только в metrics.json и test_predictions.csv. Accuracy без Recall недостаточна: Dummy правильно классифицирует большинство, но пропускает все двойки. Показатель модели не является калиброванной вероятностью. Нельзя делать выводы об отчислении, эффективности рекомендаций или статистике российского образования. Для практики нужны реальные обезличенные данные, временная валидация, калибровка и проверка человеком.
