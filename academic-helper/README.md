# Помощник по успеваемости — Россия, оценки 2–5

Автор: Азоян Иван Степанович. Учебный проект по четырём лабораторным работам «Управление данными».

**Все записи вымышлены и созданы генератором.** Учебный институт «Южный кампус» — вымышленный российский вуз. Записи не являются данными РУДН или статистикой России. Шкала каждой оценки: 2, 3, 4, 5. Цель классификации: итоговая оценка равна 2. Средние оценки могут быть дробными.

## Что подготовлено

360 студентов, 12 условных групп, 3 дисциплины и 1 080 предметных записей. Два входа: ведомость оценок `gradebook.csv` и журнал занятий/работ `activity_log.csv`. Оба созданы одним генератором; они не являются независимыми эмпирическими источниками. Внешний справочный источник — официальный справочник РУДН о традиционных оценках: https://handbook.rudn.ru/learn/rating.html. Он не подтверждает правила вымышленного вуза.

База SQLite из 7 таблиц, EDA, 6 признаков, групповые выборки, Dummy/логистическая регрессия/случайный лес, подбор параметров, 5 страниц Streamlit, поиск по 10 документам и 4 разрешённых инструмента, журнал запросов. Подробности: `docs/methodology.md`, схема: `docs/er_diagram.mmd`.

## Установка и запуск

Python 3.12. Из папки проекта:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m src.etl
streamlit run app.py --server.address 127.0.0.1
```

Архив содержит исходные CSV, модель классификации, результаты и демонстрационную базу. ETL можно повторить. Он пересоздаёт базу и очищает прежний журнал/эксперименты; для сохранения копируйте базу перед запуском. Веса LLM в архив не включены.

## Полное воспроизведение

```bash
python -m src.generate_data
python -m src.etl
python -m src.train
python -m src.evaluate_agent
pytest -q
```

Зерно генератора и разбиения — 42. Преднамеренно добавлены 5 дублей ведомости, 12 дублей журнала, 3 пропуска второй контрольной и пробелы в коде дисциплины. ETL удаляет дубли, нормализует коды и отсекает будущие события; пропуски заполняются медианой внутри обучающего Pipeline. Срез: 29.03.2026, конец восьмой недели условного весеннего семестра. Итоговые оценки используются только как цель.

## Помощник и локальная языковая модель

Без ключей работает режим «Автономный режим» с проверенными ответами инструментов. На Mac с Apple Silicon можно подключить настоящую локальную Qwen3-1.7B-4bit:

```bash
python -m pip install -r requirements-local-mac.txt
python -m src.download_model
python -m src.evaluate_local
streamlit run app.py --server.address 127.0.0.1
```

Скачивание около 1 ГБ, без аккаунта. Путь весов `data/models/qwen3`. Выбор функции в локальном режиме выполняют правила; LLM формирует объяснение. Проверка чисел не гарантирует смысловой правильности. На 16 разработческих вопросах: 16 генераций, 10 полных ответов, 1 неполный, 5 ошибочных; среднее 1 438 мс. Под объяснением всегда добавляются проверенные сведения. Для фактов предпочитайте режим «Автономный режим» и сверяйте источники.

Внешний Responses API опционален: задайте `OPENAI_API_KEY` и `OPENAI_MODEL` через окружение, как в `.env.example`. Ключ не помещайте в код. Реальный внешний запрос не проверялся; интеграция проверена имитацией клиента. Для неё нужен отдельный аккаунт и доступ к API.

## Полученные результаты

Выборки по студентам: 216/72/72 человек, 648/216/216 записей. Все 3 предмета одного студента находятся в одной выборке. Выбрана логистическая регрессия C=1 по CV Average Precision 0,7969; порог 0,45 выбран по F1 на валидации. На тесте: Precision 0,5253, Recall 0,8000, F1 0,6341, ROC AUC 0,8161. Ошибки: TN=104, FP=47, FN=13, TP=52. 95% групповой bootstrap-интервал F1 [0,536; 0,722]. Случайный лес имеет тестовый F1 0,6573, но тест не используется для пересмотра выбора.

Результаты характеризуют зависимости генератора, а не качество на реальных российских студентах. Сигнал риска не означает отчисление и не является гарантированной вероятностью. 23 автоматические проверки пройдены. Поиск: ожидаемый документ в top-3 для 9/9 справочных запросов на фиксированном разработческом наборе.

## Структура

- `src/` — генератор, ETL, обучение, инструменты, LLM и оценки.
- `data/raw/` — два синтетических CSV; `data/knowledge/` — справочные тексты.
- `artifacts/` — модель, метрики, разбиение, прогнозы и графики.
- `tests/` — проверки очистки, времени, разбиения, инструментов и интерфейса.
